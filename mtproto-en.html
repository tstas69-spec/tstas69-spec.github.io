How to Set Up an MTProto Proxy for Telegram: Step-by-Step Guide

MTProto for Telegram is the most popular proxy for uninterrupted messenger operation. This proxy is the official Telegram protocol.

In this 3-step guide, you will learn how to quickly install an MTProto proxy for Telegram on a rented server and connect it to your messenger.

Requirements for Installing an MTProto Proxy for Telegram

Minimum requirements

  • Operating system: Ubuntu 20.04 / 22.04 (clean installation)
  • Server (VPS): 1 core, 512 MB RAM — that's enough
  • SSH access (root or a user with sudo)
  • Open port 443 (needed for HTTPS masquerading)

The entire guide will be based on the example of the Aeza provider. You can use any other provider that offers VPS server rental in Europe.

Step 2 — Configure the MTProto Proxy Server for Telegram

Next, you need to enter just one command and press Enter:

sudo apt update && sudo apt upgrade -y && sudo apt install docker.io ufw -y && sudo ufw allow OpenSSH && sudo ufw allow 443/tcp && sudo ufw --force enable && SECRET=$(docker run --rm nineseconds/mtg:2 generate-secret --hex google.com) && docker run -d --name mtg --restart=always -p 443:443 nineseconds/mtg:2 simple-run -n 1.1.1.1 -i prefer-ipv4 0.0.0.0:443 "$SECRET" && echo "✅ READY LINK: tg://proxy?server=$(curl -s ifconfig.me)&port=443&secret=$SECRET"

The command is entered in full, without spaces, as is. During installation, a question will be asked; you must answer — yes. Then 3 or 4 windows will pop up, as shown in the screenshot below; you need to press Enter four times.

Installation confirmation request

The result of the installation will be a ready European server with an MTProto proxy for Telegram. See the screenshot below.

That's it, the installation is complete.

What this command does and installs on your server:

  • Updates the package list
  • Installs all system updates
  • Installs the curl utility
  • Docker is installed automatically
  • Configures the MTProto proxy on port 443
  • Enables Fake TLS technology — masquerading as regular HTTPS
  • Generates a secret key

All this takes 1–2 minutes. Just wait.

FAQ — frequently asked questions

1. Can I install MTProto on Windows?
Yes, but the instruction is more complicated. For simplicity and stability, it's better to use Ubuntu on a VPS.

2. How much traffic does the proxy consume?
Almost all traffic depends on you — how much you use Telegram. Usually no more than 2-3 GB per month.

3. How do I remove the proxy?
On the server, run:

docker stop mtproto-proxy && docker rm mtproto-proxy

4. Do I need to renew the server every month?
Yes, it's a rental. If you don't renew it, the proxy will turn off. Telegram will simply stop connecting, and you'll return to regular internet without a proxy.
