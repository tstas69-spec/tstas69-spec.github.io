如何为Telegram设置MTProto代理：分步指南

Telegram的MTProto是保证即时通讯软件不间断运行的最流行代理。该代理是Telegram的官方协议。

在这份3步指南中，你将了解如何在租用的服务器上快速安装Telegram的MTProto代理，并将其连接到你的即时通讯软件。

为Telegram安装MTProto代理的要求

最低要求

  • 操作系统： Ubuntu 20.04 / 22.04（全新安装）
  • 服务器（VPS）： 1核，512 MB RAM — 这就足够了
  • SSH访问（root或具有sudo的用户）
  • 开放端口443（用于伪装成HTTPS）

整个指南将以Aeza提供商为例。你可以使用任何其他在欧洲提供VPS服务器租赁的提供商。

第2步 — 为Telegram配置MTProto代理服务器

接下来，只需输入一条命令并按Enter：

sudo apt update && sudo apt upgrade -y && sudo apt install docker.io ufw -y && sudo ufw allow OpenSSH && sudo ufw allow 443/tcp && sudo ufw --force enable && SECRET=$(docker run --rm nineseconds/mtg:2 generate-secret --hex google.com) && docker run -d --name mtg --restart=always -p 443:443 nineseconds/mtg:2 simple-run -n 1.1.1.1 -i prefer-ipv4 0.0.0.0:443 "$SECRET" && echo "✅ 准备好的链接: tg://proxy?server=$(curl -s ifconfig.me)&port=443&secret=$SECRET"

命令需完整输入，不加空格，照原样输入。安装过程中会问一个问题，需要回答 — yes。然后会弹出3或4个窗口，如下面的截图所示，需要按Enter四次。

FAQ — 常见问题

1. 可以在Windows上安装MTProto吗？
可以，但说明更复杂。为了简单和稳定，最好在VPS上使用Ubuntu。

2. 代理消耗多少流量？
几乎所有流量都取决于你 — 你使用Telegram的时间。通常每月不超过2-3 GB。

3. 如何删除代理？
在服务器上执行：

docker stop mtproto-proxy && docker rm mtproto-proxy

4. 需要每月续费服务器吗？
是的，这是租赁。如果不续费，代理将关闭。Telegram将只是停止连接，你将回到没有代理的普通互联网。
